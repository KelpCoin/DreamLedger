# Figure Eight SEO Acquisition Contract v1

SEO is an acquisition rail inside the Figure Eight.

It is not permission to mass-publish pages.

A page can be drafted from observed demand, but publication is a consequential external action and therefore remains behind the durable human authorization boundary.

SEO evidence hierarchy:

1. Direct observed demand
2. Independent external evidence
3. Existing DreamLedger telemetry
4. Existing governed commercial records
5. Derived query expansion
6. Hypothesis

Only levels 1-4 may establish VERIFIED demand evidence. Levels 5-6 are proposals.

Every page records:
- query intent
- source fossil
- independent source count
- freshness
- canonical URL
- title
- meta description
- structured data
- internal links
- body hash
- publication approval
- publication receipt

SEO learning is tied back to economic truth. Impressions, clicks, rankings and page views are telemetry, not revenue.

Only a complete external economic chain can produce a reusable mechanism.
