# PUBLIC WORLDS SURFACE
Date: 2026-09-29

The public worlds catalogue is available at /worlds and /silos.

It currently exposes the curated customer-facing catalogue rather than dumping internal database rows. Each listed world has a public route, description and price where applicable.

The production database currently contains 1,000,017 cube_silos records. That is an internal substrate count, not a claim that 1,000,017 customer-ready markets exist.

The public catalogue therefore promotes only surfaces that have been prepared for public consumption.

Internal orchestration names remain private.

No public footage currently proves autonomous end-to-end swarm execution. The Evidence page states this explicitly.

Next promotion rule: a world can move into the public catalogue only when its public route, customer-facing description, offer/commission path, provenance and applicable evidence requirements are satisfied.
