# OPPORTUNITY MASS ADMISSION V1

Objective: scale discovery without scaling human attention.

Target operating shape:

200,000 OBSERVED -> 50,000 QUALIFIABLE -> 10,000 CAPABILITY-MATCHED -> 1,000 TRAVERSABLE -> 100 EXECUTABLE -> 10 HUMAN-GATED -> 1+ REAL TRANSACTION -> VERIFIED -> REPLICATE

These are target funnel shapes, not observed conversion rates.

Admission order:
1. Evidence exists.
2. Confidence and commercial relevance clear qualification thresholds.
3. Required capabilities are known.
4. Authority is confirmed.
5. A legitimate traversable path exists.
6. Human gates remain separate from fully executable work.
7. External authorization must be explicit before EXECUTABLE.
8. Unknown authorization is never upgraded by inference.

State semantics:
- REJECTED: weak or insufficiently evidenced demand.
- QUALIFIABLE: demand is qualified but capability coverage is incomplete.
- CAPABILITY-MATCHED: capability identifiers exist but the economic path is not yet confirmed.
- TRAVERSABLE: a legitimate path exists, but execution authorization is not explicit.
- EXECUTABLE: capability, authority, traversability, and explicit authorization are present.
- HUMAN-GATED: a legitimate path exists but a human or external gate remains.

The evaluator is deterministic and can process large batches. It does not bid, contact, pay, checkout, or escalate authority.

Current production baseline on 2026-09-29: 131 cube opportunities, 10 INTERESTING, 14 execution packets, 0 verified economic outcomes. The scaling bottleneck is therefore acquisition volume plus admission, not another catalogue page.

Next layers: feed adapters -> mass admission -> capability matching -> traversability -> execution frontier -> verified transaction -> replication template.
