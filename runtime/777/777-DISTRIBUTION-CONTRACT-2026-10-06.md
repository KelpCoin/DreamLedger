# 777 DISTRIBUTION CONTRACT

The 777 cell is now connected to a reusable social-distribution actuator contract.

The actuator supports authorized publication to owned/authorized Tumblr and X accounts only. It does not scrape, DM strangers, bypass platform controls, or manufacture engagement.

Canonical flow:

CELL_ID → UTM TARGET → MESSAGE → AUTHORIZED SURFACE → PUBLICATION RECEIPT → TELEMETRY → CHECKOUT → SETTLEMENT → FULFILLMENT → TRUTH

Default behavior is dry-run. External publication requires the explicit repository secrets TUMBLR_ENABLED=true and/or X_ENABLED=true plus the corresponding authenticated credentials.
