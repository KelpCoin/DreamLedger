## 777 gate

Every feature is subordinate to real external behavior.

The system should instrument:
EXPOSURE → RESPONSE → QUALIFIED RESPONSE → ACCOUNT → LISTING/WANT → TRADE/BUY INTENT → SETTLED PAYMENT → FULFILLMENT → EVIDENCE

Synthetic traffic, generated users, internal DB rows and model preference never count as community demand or economic truth.

## Anti-gatekeeping boundary

Moderation protects against fraud, abuse, illegal activity and platform integrity. It does not determine legitimate prices, collection preferences, profile aesthetics, or ordinary participation based on moderator preference.

Reputation should be explainable and primarily behavior-derived. Automated risk signals may assist review, but an algorithm must not silently become an unappealable authority.

## Expansion

The underlying primitives should be reusable across future lawful TCG categories and other domains. MTG TCG remains the only active domain expansion target until real demand justifies widening the silo.

CUBE may generate future domain and feature candidates. 777 determines which candidates earn exposure. Real external response determines which candidates earn deeper engineering.

## Immediate target

Do not build all 45 roadmap items now.

Make this loop excellent:

VISITOR → FIND CARD / SEE PROFILE → CREATE PROFILE → HAVE/WANT/SELL → REAL HUMAN RESPONSE → LEARN → MUTATE

Then pursue the first real NZ community cohort.
