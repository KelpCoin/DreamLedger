# ECONOMIC PINBALL / NETWORK NUDGE CONTRACT — 2026-10-02

## Purpose

Network Nudge is the learning membrane for the DreamLedger / BrownEye Cortex commercial loop.

It lets later LLMs inherit compact, provenance-bound evidence about prior commercial experiments instead of rediscovering the search space from zero.

The nudge is guidance, not truth.

## Core rule

**DO NOT SHOOT IN THE DARK. FOLLOW OBSERVED SIGNALS.**

The next 777 cell should be influenced by what reality has already taught the system.

## Pinball model

The LLM is the ball.

Evidence, proven cells, promising cells, failed cells, constraints and human gates are the bumpers.

A PROVEN mechanism creates a stronger positive nudge.
A NEGATIVE mechanism creates a negative nudge.
An UNTESTED mechanism creates no economic nudge.
A BLOCKED mechanism creates an execution nudge, not a demand nudge.
A STALE or CONTRADICTED mechanism loses authority.

The system biases exploration. It does not predetermine the answer.

## Strength

Positive nudge strength increases with:

1. independent external observations
2. repeated observations
3. attributed settled payments
4. fulfilled outcomes
5. independent evidence
6. low human effort per outcome

Strength decreases with:

1. contradiction
2. staleness
3. failed replication
4. high human burden
5. changed context

## 777 selection

Use network nudges to:

- mutate around observed successes
- avoid repeatedly testing disproven combinations
- explore adjacent audiences
- explore adjacent messages
- explore adjacent surfaces
- explore adjacent CTAs
- revisit promising offers under changed conditions
- preserve controlled exploration

The objective is not maximum exploitation. Maintain exploration so the system can discover better regions.

## Dollar-following rule

When a verified economic outcome occurs:

**FOLLOW THE DOLLAR BACKWARD.**

Recover:

OFFER -> AUDIENCE -> MESSAGE -> SURFACE -> CTA -> RESPONSE -> PAYMENT -> FULFILLMENT -> EVIDENCE

Then generate neighboring cells and replicate.

One transaction is a signal, not proof of repeatability.

## Anti-theatre

Never convert:

model preference -> demand
internal usage -> external demand
impressions -> buyers
checkout starts -> revenue
payment links -> revenue
synthetic traffic -> demand
self-purchases -> validation
one anomaly -> repeatability

Network Nudge remains subordinate to the existing economic truth boundary.

## Learning membrane

OBSERVE -> RECORD -> CLASSIFY -> NUDGE -> SELECT -> EXPOSE -> OBSERVE AGAIN

This is the mechanism by which one LLM worker can leave useful commercial memory for the next worker.
