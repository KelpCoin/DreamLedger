## Recovery order
REPAIR -> REROUTE -> QUARANTINE -> ESCALATE.

Repair the smallest reversible boundary first. If it cannot be repaired, reroute to an existing authorized fallback. Quarantine only the affected branch. Escalate to Biggie only for identity, consent, payment authority, platform permission, legal/financial commitment, irreversible action, or kill-switch decisions.
