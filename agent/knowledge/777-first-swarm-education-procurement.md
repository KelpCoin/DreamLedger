# 777 First Swarm: Education Construction Procurement Intelligence

Status: UNVERIFIED TEST POPULATION

Parent gravity:
Education construction procurement and subcontractor quote normalisation.

Do not merge this population with MTG, HappyHomarid, CollectorsCoast, Amplissa/adult, or PhinHaven silos.

## Candidate 01: Quote Normalisation

Audience: main contractor bid teams
Message: Turn 2–5 subcontractor quotes into one line-item-matched comparison.
Surface: direct contractor outreach
CTA: Request a sample comparison
Primary metric: qualified external response

## Candidate 02: Tender Risk Scan

Audience: commercial managers
Message: Identify missing scope, exclusions, incompatible units, and pricing anomalies before tender submission.
Surface: procurement-intelligence landing page
CTA: Submit one anonymised quote set
Primary metric: quote-set submission

## Candidate 03: Bid Pack Reconciliation

Audience: estimators
Message: Reconcile supplier quotes against the bid package and expose unresolved line items.
Surface: trade-specific landing page
CTA: Run one paid reconciliation
Primary metric: paid order

## Candidate 04: Education Project Cost Evidence

Audience: quantity surveyors / commercial teams
Message: Produce an evidence-linked supplier comparison that preserves source documents and assumptions.
Surface: professional referral/channel
CTA: Request an evidence sample
Primary metric: qualified conversation

## Candidate 05: Supplier Comparison API

Audience: construction software / procurement operators
Message: Send quote files to a deterministic comparison endpoint and receive structured line-item output.
Surface: API/product surface
CTA: Run a sample payload
Primary metric: API trial request

## Selection rule

No candidate wins because it sounds good.

Candidate ranking must use observed telemetry:
1. qualified external response
2. evidence of real problem
3. willingness to submit real input
4. payment intent
5. settled payment
6. fulfillment success
7. repeat demand

A candidate with no external evidence is dropped or refined.

A settled payment is economic evidence, but only the existing DreamLedger observation/verification contract can mark a result VERIFIED.

## Swarm law

Five candidates are enough to create a measurable first cell.

If one demonstrates materially stronger external response, allocate more substrate to that candidate. Do not multiply weak candidates merely to increase page count.

Next swarm should be generated from what the first swarm teaches.
