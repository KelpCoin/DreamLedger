PHINHAVEN

A shared world that begins as a chat room and a hotel — and slowly becomes something much bigger.

STAGE 0 · LIVE INTENT · CHAT + HOTEL

Right now you can claim a room, hang out, and talk.
Over time it gains territory, farming, crafting, and real progression.
Everything is built in public. Early players help decide what comes next.

No combat power for sale. No PvP. No claim of a finished MMO.

Enter hotel (TEST · local) Shallows slice DreamLedger home

Hotel UI is browser localStorage until Supabase Stage 0 migration is applied and wired. It is not multi-device production presence.

What it is today

  • Public roadmap and honest Stage 0 framing
  • TEST hotel/chat (same browser / tabs)
  • Shallows vertical-slice scaffold (Godot + browser)
  • SQL migration ready for rooms, presence, messages (not claimed applied)

No combat. No economy. No pressure. Just a room and the people in it — while the rest is still being built.

Where it’s going

Stage Name What players get Status
0 Chat + Hotel Claim a room, talk, exist Live intent
1 Shared Spaces Furniture, basic persistence, room memory Next
2 Territory Guilds claim land — all PvE contests Planned
3 Gathering Chop, mine, fish, simple crafting Planned
4 Farming Crops, animals, seasons Planned
5 Life Sim NPCs, relationships, festivals Planned
6 Combat & Dungeons Real fights, gear, progression Planned
7 Long-term Persistent PvE world, strong community tools Vision

Target feel: better than Faldon, around Diablo 2 depth, heavy community focus. All player conflict stays PvE — guilds fight the world and the systems, not each other.

How we build it

  • Everything starts small and slightly embarrassing on purpose.
  • We ship the next useful piece, then the next.
  • Roadmap is public and will change based on who actually plays.
  • No pay-to-win combat. No surprise PvP.

Current rules (Stage 0)

  • Be decent.
  • Don’t grief rooms that aren’t yours.
  • Feedback is welcome. Demands are not.
