Trust layer

Proof is a product.

FIRST_PAYMENT_PROOF is only issued when the system observes the commercial event. The public surface keeps health, catalogue, checkout and payment evidence separate.

Evidence before claim.

A proof artifact binds an observed payment event to an offer, timestamp and transaction identifier.

{
  "event": "checkout.session.completed",
  "offer_id": "EDH_0001",
  "evidence_level": 1,
  "status": "OBSERVED"
}

Separate the facts.

Runtime health is not payment proof. Catalogue presence is not a sale. A checkout URL is not a completed transaction.

HEALTHZ    → runtime
OFFERS     → catalogue
CHECKOUT    → purchase surface
WEBHOOK    → payment event
PROOF      → observed evidence
