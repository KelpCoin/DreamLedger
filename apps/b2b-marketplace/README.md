# TradeGrid B2B

B2B-first marketplace foundation for buying, selling, sourcing, wholesale and procurement.

Core primitives: verified business identity, structured inventory, fixed/negotiable/RFQ/auction pricing, bulk quantities, supplier quotes, procurement, order/payment/fulfillment/dispute states and verified transaction evidence.

Current status: V1 foundation. Landing/browse surface and Supabase transactional schema are implemented. Auth, RLS policies, payment integration, messaging, search indexing, logistics and production deployment are still gated work.

Economic truth rule: listings, clicks, offers and internal orders never count as verified revenue. Revenue requires an independent external buyer, settled payment, attributable transaction and fulfillment evidence.
