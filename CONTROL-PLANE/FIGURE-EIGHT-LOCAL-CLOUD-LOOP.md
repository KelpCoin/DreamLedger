# Figure-eight — local Gauntlet / Elohim ↔ live dreamledger.org

Two loops that cross; neither replaces the other.

```
        LOCAL (PC on)                         CLOUD (live)
   ┌─────────────────────┐              ┌─────────────────────┐
   │ Gauntlet / candidates│──propose───▶│ catalogue / surfaces │
   │ Elohim-class local   │              │ Stripe / webhooks   │
   │ compile / verify     │◀──evidence──│ /version / offers    │
   │ PowerShell orchestra │              │ proof artifacts     │
   └─────────────────────┘              └─────────────────────┘
              \                              /
               \         FIGURE-8           /
                \         crossing         /
                 \    GitHub main + CI    /
                  \______________________/
```

## Clash rules (intentional friction)

| Local says | Cloud must |
|---|---|
| Candidate offer looks good | Still **gated** until checkout + fulfilment verified |
| Gauntlet PASS | Not revenue; only “allowed to propose live” |
| Elohim / autonomy cycle | No public spend without approval gate |
| Compiled surface pretty | Live SHA must converge; doorways 200 |
| Soft metrics (sim traffic) | **Forbidden** as revenue |

Local invents and stress-tests. Cloud settles money and proof. GitHub is the crossing point.

## Local plane (computer on)

- `BEC-PRIME/gauntlet/*` — CandidateGauntlet, FirstSaleGate, OpportunityGauntlet, GauntletV6  
- compile scripts, worker pool, autonomy cycles  
- Kelplantis compilers (scarcity, dungeon)  
- Cost: electricity + attention  

## Cloud plane (always-on commerce)

- `public/` storefront, `cube.json`, agent discovery  
- Stripe Payment Links + webhook fulfilment  
- Render deploy from main  
- Heartbeat / surface deploy gates  

## Figure-eight cadence

1. Local: generate candidate (offer, skin, silo, game economy)  
2. Gauntlet: reject fantasy claims  
3. Commit to GitHub (crossing)  
4. Cloud: deploy / gate / live probe  
5. Evidence back to GitHub proof  
6. Local: learn, next candidate  
7. Only after paid proof: clone silo skin (white-label upscale)  

## Style target

- **Storefront:** catalogue rails, CTA cards, silo separation, honest scarcity  
- **CUBE:** evergreen reskin, not one-off themes  
- **Game:** Habbo visit + depth scarcity + billboards that settle on same spine  
- **Voice:** evidence before hype — same on local and live
