# V47 Tollbooth / Economic Utility Layer Doctrine

Locked 2026-09-28

## Core Thesis
The business is a self-running economic utility layer, not freelancing or a generic AI product.

A machine sits in a flow where money, data, verification, computation or decisions are already moving.
It performs a tiny legitimate operation, meters it, collects a small fee, produces proof, fulfils automatically, and repeats.

Pattern:
REQUEST / EVENT → OPERATION → RESULT → METER → PAYMENT → RECEIPT / PROOF

or

RESOURCE → CONSUMPTION → METER → BILL

## Promotion Rule (unchanged)
Signal ≠ buyer
Buyer ≠ payment
Payment ≠ fulfilment
Fulfilment ≠ proof
One sale ≠ repeatability

Only repeated external attributable outcomes earn automation.
