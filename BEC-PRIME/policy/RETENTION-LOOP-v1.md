# RETENTION LOOP v1

Purpose: make return visits meaningful rather than rewarding login alone.

## DAILY LOOP

Discovery -> Trust -> Identity -> Transaction -> Ownership -> Participation -> Contribution

A streak advances through meaningful actions, not a page-load counter.

## LANDING SURFACE

The general landing page should expose three rotating auction lanes:

1. Dreamiez / consumer world
2. Kelp Atlantis / shared asset world
3. B2B capability marketplace

Each lane must use real backend auction data when available. Empty or unavailable data must be labelled honestly.

## TICKERS

Global ticker: market/news/activity signals relevant to the whole ecosystem.

Silo ticker: each silo gets its own ticker stream. A silo ticker must not leak state, inventory, identity, or offers from another silo.

## ENCOURAGEMENT

After each meaningful action, show concrete progress toward the next stage. Avoid manipulative urgency, fake scarcity, fabricated activity, or invented social proof.

## DREAMIEZ

Daily return loop should surface:

- current streak
- progress stage
- one tiny next action
- new asset/market signal
- reward or ownership state when genuinely earned

## B2B

B2B is a separate commercial surface. It can link from the general front door, but B2B records and offers remain silo-controlled.

## TRUTH GATE

No auction winner, bid, streak reward, sale, scarcity claim, or news event is rendered as real unless backed by a real data source or ledger event.
