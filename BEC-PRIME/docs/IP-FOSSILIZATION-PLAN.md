# BrownEye Cortex IP Fossilization Plan

Purpose: preserve and structure the user's ChatGPT-originated intellectual property without placing the private ChatGPT export into this public repository.

## Data boundary

The raw ChatGPT export MUST remain outside this public repository.

Expected private source:

D:\BrownEyeCortex\RAW\chatgpt-export.zip

Expected private archive:

D:\BrownEyeCortex\IP-ARCHIVE\

## Pipeline

RAW -> NORMALIZED -> EXTRACTED -> CANONICAL -> PROOF

RAW is immutable. NORMALIZED is derived from RAW. EXTRACTED contains classified IP objects. CANONICAL contains authoritative deduplicated material. PROOF contains hashes, manifests, counts, and provenance.

## Provenance rule

Every extracted canonical object should retain enough provenance to locate its source conversation and message content in the private RAW/NORMALIZED layers.

## Public repository rule

This repository may contain extraction tooling, schemas, documentation, and non-sensitive proof metadata. It must not contain the raw ChatGPT export, private conversation text, credentials, private payment information, or other sensitive IP that should remain private.

## Completion condition

The fossilization project is complete only when:

1. RAW export is preserved privately.
2. SHA-256 hashes exist for source and derived layers.
3. Conversations are indexed.
4. IP is classified into silos/categories.
5. Canonical objects have provenance.
6. A proof manifest records counts and hashes.
7. Public GitHub contains no raw private export.
