# Shared Avatar Asset Registry

Every avatar, cosmetic, armor, accessory, emote, and background generated for Dreamiez or Kelp Atlantis is one canonical asset.

The Demand Radar and ecosystem agents seed demand. The Elohim Refinery generates/refines the asset. The Gauntlet judges consumption readiness. The approval governor controls publication or commerce.

An asset is not complete until both `dreamiez` and `kelp-atlantis` render targets exist. No manual ecosystem duplication is permitted.

The browser surface is phone-first and uses portable VRM/glTF representations so the same canonical SKU can travel between the two ecosystems.
