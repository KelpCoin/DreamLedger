Security & Trust

This page describes the authority boundary behind DreamLedger's agent tooling. The public site does not grant an AI model authority to publish, charge, delete or execute arbitrary commands.

Model: propose only

Gemma may inspect allowlisted information and propose offers or checkout actions. Proposals enter the Economic Court and cannot create a payment session.

Economic Court: human approval

Checkout proposals move through PROPOSED → COURT_CHECKED → AWAITING_HUMAN_APPROVAL → HUMAN_APPROVED → EXECUTABLE. No autonomous spend authority exists.

MCP: six allowlisted tools

The gateway exposes only read-only or proposal-only tools. Tool definitions are pinned by SHA-256 and changes require re-verification.

Sandbox: no network

The hardened local configuration runs the MCP gateway in a Docker container with a read-only filesystem, no network, dropped Linux capabilities and no-new-privileges. Product and proof inputs are mounted read-only; only the audit volume is writable.

Proof is not revenue

Architecture, deployment, page views and AI assertions do not count as revenue. RA_000001 remains a real stranger payment with independent settlement evidence.
