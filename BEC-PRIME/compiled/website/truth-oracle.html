EVIDENCE BOUNDARY

Evidence is not the same thing as a claim.

OBSERVED, INDEPENDENTLY VERIFIED, SOURCE SUPPORT, DERIVED, INFERRED, CONTRADICTED and UNKNOWN are distinct states. A source is not automatically an observation. A file, database row, checkout session or test payment is not by itself proof of a real-world event.

Truth Oracle can be wrong. Evidence can change. Contradictions stay visible.

The public surface explains the evidence model without exposing protected implementation details.
