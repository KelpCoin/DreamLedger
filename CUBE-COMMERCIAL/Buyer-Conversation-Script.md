# Buyer Conversation Script — Neutral Diagnostic

STATUS: ACTIVE
ENGINEERING: FROZEN

Use only warm contacts / introductions.

## Open

I’m researching how enterprises are managing AI agents that hand off
financial state across systems like Salesforce, SAP, Oracle, Workday,
and treasury platforms.

How does your team currently prove after the fact that the whole
cross-system transition was authorized and valid?

## Probe

Is that proof currently based on each system logging its own action,
or is there an independent record across the full chain?

## If a gap appears

Who owns that risk today — finance, security, internal controls,
or AI governance?

## Budget test only after pain

Is there already budget or an initiative aimed at closing that
control/audit gap?

## Only if budget exists

Would it help to have an independent verifier that returns a
machine-readable PASS/FAIL/QUARANTINE artifact for the
cross-system transition?

## Decision Signals

NO REAL WORKFLOW        = STOP
LOGS SEEM ADEQUATE      = ASK IF FULL CHAIN IS PROVEN
WORKFLOW + GAP + OWNER  = FOLLOW UP
BUDGET/INITIATIVE       = STRONG SIGNAL
PILOT QUESTION          = COMMERCIAL SIGNAL
