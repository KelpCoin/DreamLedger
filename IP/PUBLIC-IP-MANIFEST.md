# DreamLedger Public IP Manifest

Status: PUBLIC-SAFE REGISTER

This file records public-facing commercial concepts and operating rules. It does not contain private keys, secrets, credentials, customer data, or private BrownEye/CUBE internals.

## Core commercial IP

- DreamLedger permanent digital billboard concept.
- Fixed-price billboard blocks with one-time purchase positioning.
- Regional billboard surfaces: Worldwide, NZ, Australia, South Africa, US, Europe.
- Primary wedge: 100x100 billboard block at NZ$29.
- Manual-review fulfillment contract: board + image + destination link.
- Permanent QR doorway concept: one durable QR points to a controlled destination that can later rotate.
- Buyer-share distribution concept: purchasers can share their block and public block URL.
- Revenue truth rule: code, traffic, clicks, checkout sessions, deployments, and GitHub activity do not equal revenue. Verified payment does.

## Overlay IP

- Host-motion -> conversion-surface -> fulfillment -> receipt model.
- Permission-first acquisition: use owned or explicitly permitted promotional surfaces.
- No mass-spam, impersonation, deceptive engagement, or unauthorized placement.
- Clone only a paid, verified winner.

## Market IP

- Global-first offer framing with localized price and language variants.
- Audience-free distribution through permissioned partners, directories, communities, creator ecosystems, agencies, and physical QR placements.
- Agency/distributor test: sell the concept as a low-friction client add-on rather than treating agencies as the NZ$29 end buyer.
