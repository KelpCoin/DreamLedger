# Phone-first catalog feed (feed-v1)

## Patterns applied (mobile commerce synthesis)

| Pattern | Source cluster | Application |
|---------|----------------|-------------|
| Thumb easy zone = bottom | Hoober / mobile UX 2025 | Sticky **Buy** bar + bottom nav |
| No primary CTA top-right | Thumb-zone guides | Slim brand header only |
| Continuous vertical discovery | Temu / SHEIN / TikTok-style feeds | One scroll catalog, full-width cards |
| Price + CTA above fold per card | Amazon mobile lists | Large price + 48px Buy on each card |
| Sticky add-to-cart | Mobile PDP best practice | Dock Buy tracks in-view product |
| Bottom tabs ≤4 | Nav guidelines | Shop · Board · Account · Join |
| Large hit targets ≥44–48px | Apple/Material + CRO | All primary taps |
| Trust near checkout path | Stripe / institutional | Payment line under feed |

## Not copied

Dark “SaaS dashboard” chrome, multi-rail horizontal silos on home, floating QR.
