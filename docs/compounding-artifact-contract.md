## Non-negotiable truth rules

An artifact never upgrades its own truth state.

UNVERIFIED remains UNVERIFIED.
TEST remains TEST.
SIMULATED remains SIMULATED.
Only the existing economic truth machinery can establish VERIFIED.

A payment intent is not automatically revenue.
A checkout is not a buyer.
A prepared dispatch is not an external dispatch.
A hypothesis is not a counterparty commitment.

## Compounding mechanism

Artifact N becomes reusable input for artifact N+1.

The system compounds:

1. verified buyer/problem patterns
2. evidence patterns
3. capability lineage
4. fulfillment knowledge
5. failed hypotheses and negative knowledge
6. reaction-time observations
7. offer and price evidence

The objective is not a larger pile of pages. The objective is increasing economic capability per unit of new cognition.
