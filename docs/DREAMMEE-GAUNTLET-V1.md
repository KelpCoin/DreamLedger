# DreamMee World Gauntlet v1

DATE: 2026-08-23

## Gate 0: Canon

PASS when the canonical world specification exists and names the five primitives, 100-floor topology, boss gate, DreamMee identity, MTG simulation layers, AI approval boundary, and economic truth rule.

## Gate 1: Identity

PASS when a DreamMee can be created or resolved by a stable player identifier and its state can be read back deterministically.

## Gate 2: World

PASS when Floor 1 exists as an addressable surface and floor progression is represented by versioned rules/events.

## Gate 3: Boss

PASS when a canonical boss defeat produces an immutable event and deterministic unlock consequences.

## Gate 4: Asset provenance

PASS when an asset has an owner, acquisition source, timestamp, and provenance reference.

## Gate 5: MTG simulation

PASS when a deck can be represented as canonical input and Monte Carlo plus deterministic replay can produce reproducible output.

## Gate 6: Economic truth

PASS only when an authorised settlement source reports a real paid transaction. Database flags alone are insufficient.

## Gate 7: Reconciliation

PASS when the payment is mapped to an idempotent economic event and duplicate processing cannot create duplicate revenue events.

## Gate 8: Fulfillment

PASS when verified payment evidence creates a deterministic fulfillment work item without automatically contacting the buyer.

## Gate 9: Proof

PASS when reconciliation and fulfillment state produce machine-readable proof artifacts with SHA-256 hashes.

## Gate 10: Refinement

PASS when AI proposals are separated from production mutation and require simulation/governance/human approval before release.

## Current economic truth

The DreamLedger commerce spine currently defines a NZ$29 Commander Deck Diagnostic settlement path. Its workflow accepts only live, paid, NZD Checkout Sessions tied to the configured Payment Link and totaling NZ$29. The first real matching session is the economic ignition event.

## Millionaire gate

Architecture PASS is not revenue PASS.

Revenue milestones require cumulative verified settlement evidence:
NZ$1 -> NZ$10 -> NZ$100 -> NZ$1,000 -> NZ$10,000 -> NZ$100,000 -> NZ$1,000,000.

Each milestone must be supported by settlement evidence and an idempotent economic ledger, not projections.
