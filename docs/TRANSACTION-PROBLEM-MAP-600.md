## Economic boundary

P301-P600 are problem applications, not revenue claims. A problem becomes economically real only when an independent buyer pays, payment settles, fulfilment occurs, and evidence verifies the outcome.

## Factory rule

300 primitives x 2 distinct problem deployments = 600 candidate applications. The factory should instantiate only where real demand, fulfilment capability and a traversable transaction boundary exist. The registry is intentionally broader than the active build frontier.
