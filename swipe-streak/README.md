# Swipe Streak Empire MVP

A first playable vertical slice for a swipe-first commerce/catalog experience.

## MVP

- Product cards grouped by silo
- Left/right swipe controls
- Right-swipe streak counter
- 10-right-swipe reward threshold
- Local-first UI with optional Supabase persistence
- MTG seed catalogue fixture
- Avatar and game-state contracts

## Boundaries

This MVP is isolated under `swipe-streak/` and does not alter the existing DreamLedger checkout or silo behavior.
