Privacy and safety

  • Sign-in is required. The server assigns ownership from the authenticated session.
  • Import does not make cards public, tradeable or for sale.
  • Exact printing identity is retained when set code and collector number are supplied. Missing identifiers remain visibly incomplete and should be reviewed.
  • If an import partially succeeds before an error, the status will say how many rows were submitted. Re-importing the same rows is designed to upsert by owner and inventory fingerprint.
