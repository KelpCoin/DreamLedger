What the GitHub reuse closes

Patterns adopted, not architecture theatre
APPLIED PATTERN

Evidence reports

ProofSignal-style rule: no mystery probability. A result must expose the evidence state and the sources behind it.

APPLIED PATTERN

Source-grounded research

Providence/OpenErrata-style workflow: investigate from retrieved source material, preserve the investigation trail, and keep uncertainty visible.

APPLIED PATTERN

Deterministic proof

Ethos-style boundary: model interpretation is not the verifier. Evidence state remains an explicit machine-readable fact.

APPLIED PATTERN

Provenance

ClaimTrace-style boundary: source identity, observation time and evidence references travel with the claim.

CAPABILITY GAP

Deep retrieval

The public sandbox does not yet claim internet-wide RAG. That becomes a real build target only when a live use case proves retrieval is the blocker.

CAPABILITY GAP

External action

Analysis can prepare an action, but external outreach and live financial actions remain explicitly gated. No fake action is counted as progress.
