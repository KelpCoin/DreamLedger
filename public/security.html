Security

Published 11 October 2026. This page describes current assurance boundaries, not a certification.

Report a vulnerability

For a non-sensitive security report, use the DreamLedger issue tracker and provide a concise description, affected public URL or component, reproduction steps, and potential impact. Do not post credentials, personal information, exploit payloads that expose other people's data, or secrets. The repository issue tracker is public, so it is not suitable for confidential reports.

Current assurance

The site uses HTTPS and configured security headers. These controls are not a substitute for an independent penetration test, a vulnerability-management programme, or formal certification.

DreamLedger does not claim SOC 2, ISO 27001, a completed independent penetration test, a public SLA, or an enterprise security certification on this page.

Safe use

Do not test against systems or data you do not own or have explicit permission to assess. Avoid service disruption, data exfiltration, persistence, or access to other users' accounts.
