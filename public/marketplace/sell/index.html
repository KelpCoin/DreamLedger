Import a collection or prepare a listing. Keep unverified supply private until it passes the publication gate.

02 · PROVE

Attach evidence

Use photos, condition data and category fields so the listing describes the asset that will actually be fulfilled.

03 · SELL

Route to settlement

Checkout is exposed only when the listing has a compatible commercial rail. A payment becomes marketplace truth only after settlement is verified.

Seller API

The marketplace is being built API-first. The intended seller contract is a single listing resource for create, update, media, inventory and publication state, with evidence and commercial state kept separate from listing copy.

Current public intake: authenticated collection import at /collection-import/. General seller API credentials and payout onboarding are not being advertised as live until their production controls exist.
DreamLedger commercial truth: a listing is not a sale, a checkout click is not a payment, and payment is not fulfilment. Seller claims and marketplace scale remain subject to evidence.
