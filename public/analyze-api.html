Make the evidence gaps visible.

BECK Evidence Triage accepts a claim and user-supplied source details, inventories missing provenance, and returns a reproducible SHA-256 input receipt. It does not fetch source pages, determine factual truth, or certify authenticity.

Try the bounded API

Input is processed in memory by the API. No application database stores the request; hosting infrastructure may log requests. Don't submit confidential material.

Results appear here.

API contract

POST /api/v1/analyze · JSON · max 8KB request, 1,000-character claim, 10 unique sources.

{
  "claim": "Supplier A offers delivery within 14 days.",
  "sources": [{
    "url": "https://example.org/quote",
    "excerpt": "Lead time: 14 days",
    "observed_at": "2026-10-27"
  }]
}

The response includes verdict: "NOT_VERIFIED", missing-evidence flags and an SHA-256 receipt for the normalized input. A receipt cannot prove a source is real or the claim is correct.
