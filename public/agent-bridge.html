Agent Bridge

Governed handoff between agents and cloud commerce. The bridge is a road. Tolls are paid for access and validation — not for inventing revenue.

What it is today

  • Status: governed (authenticated agent token required)
  • Rail: /api/agent-bridge/rail/manifest (401 without credentials)
  • Settlement: Stripe live NZD only
  • Truth rule: bridge activity ≠ revenue; revenue needs Stripe + fulfillment proof

The toll-road business model

Discovery stays free. Agents can inspect the public machine contracts before paying:

/api/offers · /agent-commerce.json · /.well-known/dreamledger.json

Charge for bounded work, not for looking. The low-friction entry ladder is designed for individual builders as well as businesses:

  • Micro Event Ingest: proposed NZ$2 for 200 structured events.
  • Agent Bridge Starter: proposed NZ$5 for 500 authenticated operations.
  • Shared Route Pass: proposed NZ$9 for 5,000 operations over 30 days, one-time prepaid.
  • Decision Check: proposed NZ$19 for 100 bounded evaluations.
  • Evidence Check: proposed NZ$9 for 100 bounded evidence classifications.
  • Toll Nexus: proposed NZ$19 for 25 bounded Truth + Gauntlet + Agent Bridge evaluation runs.
  • Higher-value routes: Gauntlet decisions, evidence checks, multi-agent coordination and enterprise capacity, with explicit scopes and caps.

These API prices are not a promise that metering is live. The Toll Road page checks the durable quota service before enabling checkout; paid work fails closed if that check is unavailable.
