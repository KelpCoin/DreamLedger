How the toll road earns money

  1. Discover free. An agent reads public offers and the bridge manifest. Cheap health and discovery reads stay free within reasonable limits.
  2. Buy an entitlement. The future dedicated API Starter Pack checkout will sell 100 calls for NZ$19. Stripe settlement, not a success-page redirect, triggers fulfillment.
  3. Receive a scoped key. The buyer receives a revocable token tied to the canonical SKU and a bounded allowance. Secrets are not written to public logs.
  4. Pay per allowance, not per mystery. Each billable operation reserves one unit atomically. Replays with the same idempotency key return the original result without charging twice. At zero, execution stops until a top-up.
  5. Prove delivery. Request ID, correlation ID, result, entitlement, usage and settlement are reconciled through the existing commerce and economic-observation spine. API activity alone is never called revenue.

What counts as billable?

  • Billable: authenticated event writes, job claims/completions, and explicitly metered work routes.
  • Free: public catalogue/manifest reads, health probes, rejected requests before authorization, and retries carrying the same idempotency key.
  • Never silently overdraw: a depleted pack returns a machine-readable quota response without performing the requested side effect.
  • No second ledger: use the existing entitlement and economic-observation contracts. If atomic quota enforcement is unavailable, fail closed instead of faking a balance.
