# DreamLedger Silo Factory

The factory creates candidate economic surfaces from observed demand signals and bounded offer templates.

Lifecycle: CANDIDATE -> RESEARCH -> QUALIFIED -> SELLABLE -> ACTIVE -> VERIFIED.

Candidate rows are not buyers, sales, revenue, fulfillment, or verified outcomes. Provenance explicitly records that a demand signal is not a verified buyer.

Current registry: 5,000 candidate silos. Target capacity: 500,000. Public visibility: zero.

Cloud agents:
- silo-factory
- silo-orchestrator
- elohim-cube
- gauntlet-cube
- truth-oracle-execute

Elohim is queued until a candidate has a real commerce cell. Gauntlet can challenge candidate proposals before commerce activation. Truth Oracle remains the independent background verifier.

No simulated revenue, fake buyers, self-purchases, fabricated evidence, or autonomous public release.
