Acceptance criteria format

Write each criterion so that a reviewer can decide what evidence would satisfy it.

  1. Criterion: The deliverable contains a documented API endpoint list.
  2. Pass evidence: A source file or published page listing each endpoint and method.
  3. Fail evidence: The list is absent, incomplete against the stated scope, or contradicts the artifact.
  4. Human review: The criterion depends on inaccessible sources, ambiguous language, or a judgment that cannot be resolved from evidence supplied.

How the 24-hour target works

  4. Report: Findings, references, test observations, limitations, and an artifact hash where applicable are assembled.
  5. Delivery: The report is sent to the supplied email. Fulfilment is complete only when delivery evidence is recorded.
