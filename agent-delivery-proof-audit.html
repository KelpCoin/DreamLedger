Scope and acceptance criteria

One public URL or one bounded artifact; up to five criteria. Each criterion should define what evidence would satisfy it.

  1. Criterion: The deliverable lists all API endpoints in scope.
  2. PASS: A source file or published page contains the complete list.
  3. FAIL: The list is absent, incomplete against the agreed scope, or contradicted by the artifact.
  4. NEEDS HUMAN REVIEW: Evidence is inaccessible, ambiguous, or depends on judgment that cannot be resolved from the available sources.

Not included: penetration testing, legal certification, exhaustive security review, bypassing authentication, or guarantees of safety, correctness, or commercial success.
