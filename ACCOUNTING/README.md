## Fast-track rule

Do 3-5 jobs manually. Automate only steps that repeat. The Gauntlet decides whether the next automation has enough leverage to justify building it.

## Gauntlet gate

A feature is build-worthy only when the signal has repeated pain, a reachable buyer, a measurable outcome, an accepted price, and a deterministic fulfilment path.

## Elohim loop

Signal -> offer -> payment -> fulfilment -> outcome -> proof -> lesson -> approved refinement.

Elohim can recommend. Biggie approves changes to prices, promises, accounting policy, live financial actions, and public publication.
