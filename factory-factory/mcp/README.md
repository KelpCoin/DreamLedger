# DreamLedger Agent Commerce MCP

This is an additive protocol surface for the existing Factory Factory. It is not a revenue claim and does not bypass authority gates.

Transport target: MCP Streamable HTTP.
Initial tools:
- catalog_list
- quote_get
- checkout_create
- settlement_status
- proof_get

Authentication and transport encryption are deployment concerns. No credentials are embedded here. External activation remains gated until provider credentials and production verification exist.
