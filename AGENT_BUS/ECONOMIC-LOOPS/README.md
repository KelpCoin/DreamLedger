# Economic loops registry

**Internet-facing** loops may be marketed (tile, diagnostic, kits).  
**Internal** loops (bridge, sentinels) support the system but are not products.

**Local-first** loops can be prepared offline (reports, digital packs) and only complete after live Stripe pay.

See `registry.json`. Update when a loop goes live or is retired.  
Never mark revenue in this file without settlement evidence.
