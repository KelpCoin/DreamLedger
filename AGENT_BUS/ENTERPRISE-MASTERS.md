# Enterprise masters / templates

**CSS:** `public/assets/dl-enterprise.css`
**Fonts:** Instrument Serif + DM Sans

## Every public page should

1. Load fonts + `/assets/dl-enterprise.css`
2. Use `body.dl-body`
3. Header: brand + nav + one `.dl-nav-cta` pay link
4. Put secondary worlds **behind** a CTA card / band — not dumped on the first screen
5. Sticky `.dl-stick` for primary money path on mobile

## Classes

`.dl-hdr` `.dl-brand` `.dl-nav` · `.dl-h1` `.dl-lead` · `.dl-btn-gold` · `.dl-rail` `.dl-tile` · `.dl-cta-card` · `.dl-band` · `.dl-stick`

## Rule

One primary pay path on the fold. Clutter stays behind the CTA.
