# MTG listing template (0% success fee peer sales)

Use this for every seller post / future form field set.

## Required
- **Title** — Card name + set code (e.g. `Ragavan, Nimble Pilferer · MH2`)
- **Condition** — NM / LP / MP / HP / DMG
- **Finish** — Nonfoil / Foil / Etched / etc.
- **Price NZD** — Number in $NZD (not “TCG only”)
- **City / region** — e.g. Wellington, Auckland, Canterbury
- **Meetup or post** — Pickup area and/or postage terms
- **Photos** — Actual card(s), not only database art; high-value: timestamp with name+date

## Optional
- Language / altered / signed
- Quantity
- Bundle discount
- Wants for trade (card names)

## Buyer path
- No account required to message interest / pay for *platform tools*
- Peer payment: bank transfer / agreed method — prefer tracked post for high value

## Seller path
- Free DreamLedger account required to publish listing
- Platform success fee: **0%** on peer merchandise

## Safety one-liner
Public meetup · real photos · agree postage before pay · diagnostics settle on Stripe only when buying DreamLedger services.
