**Updated:** 2026-09-30  
**Truth:** Rich = repeated Stripe settlements at scale. Not a markdown file.

| Level | Monthly | Requires |

| Survive | $1–2k | ~40–70 × $29/mo |

## Engine

Attention → $29–49 pay → fast fulfil → upsell → retain → B2B → optional physical with deposit

## Phases

**0 (this week):** 20 offers, $29/$49, 24h fulfil, 3 paid or fix offer/channel.  
**1 (~$2k/mo):** templates, 10 outbound/day, no new silos.  
**2 (~$5k/mo):** listing packs, membership, LGS accounts, VA review.  
**3 (~$10k+):** brand, 10+ B2B, listing fees + featured, hire fulfiller.  
**4 (rich):** self-serve volume, real GMV, or media — only after 1–2 are real.

## Daily

Outbound before code · fulfil fast · upsell always · track offers/paid/upsell · kill non-buy-link work
