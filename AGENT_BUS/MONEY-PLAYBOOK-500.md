## Hard rules
1. Revenue only after independent external buyer + settled live payment + fulfillment + delivery evidence + attribution.
2. Prefer existing `/buy/{product_id}` routers only after a fresh public cold-path check.
3. Bridge activity, listings, clicks, checkout sessions, tests, CI and deploys are not revenue.
4. CUBE: paid + fulfilled + independently verified → then clone the mechanism.
5. Zero-upfront acquisition first. No ads spend before approval and unit-economics evidence.
6. All external publication, messages, account/payout changes and spending remain behind the existing human/policy authorization gate.
7. Manual fulfillment can prove demand only as a bounded test; automate or capacity-cap before scaling.
