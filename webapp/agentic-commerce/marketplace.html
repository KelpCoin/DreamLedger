Trust requirements for every real listing

  • Owner, provenance, licence, version, checksum and last-updated time.
  • Inputs, outputs, compatibility, usage limits, refund terms and acceptance tests.
  • Price and unit economics before an agent calls a paid tool.
  • Settlement, entitlement, fulfilment, delivery evidence and dispute path before a listing is labelled transactional.
  • GPU work requires opt-in, isolation, quotas, timeouts, no host-secret access and a data-retention policy.

Marketplace expansion queue

  1. Make one existing offer safe end-to-end: checkout, verified settlement, entitlement, fulfilment and delivery receipt.
  2. Standardise Agent Bridge capability discovery, scoped budgets, idempotency, metering and machine-readable receipts.
  3. Publish tested stencils, boilerplates, templates, word banks, evaluator packs and schemas.
  4. Add seller and buyer listing intake, moderation, provenance, search and disputes.
  5. Add DOOH placements and opt-in GPU jobs only after inventory permission, safe isolation, measured capacity and proof-of-completion exist.

Viewing this page does not create a seller account, submit a listing, initiate payment or launch a GPU job.

B2B discovery is free by design. A2A pricing must be explicit, low-cost, metered and margin-positive. Green CI is not revenue proof.
