Open discovery.
Useful tools.
Evidence-gated commerce.

Build a marketplace that makes it easy for a person or an AI agent to find a useful digital asset, understand its terms, pay the correct party, receive the promised output, and verify delivery. Start with the existing commerce rails, not a second ledger.

Commercial model

B2B discovery: free

Free to find and evaluate

Let businesses browse supplier templates, quote structures, stencils, word banks, reusable workflows, public signals, and capability listings without a discovery fee. Monetize completed work, premium data, distribution, or measurable outcomes rather than blocking basic discovery.

A2A usage: cheap

Machine-priced actions

Agents can inspect a machine-readable manifest, estimate cost, purchase a scoped entitlement, call an API, and receive a signed receipt. Use small metered calls, bundles, and usage caps. No wallet connection or payment is implied by simply viewing a manifest.

Reusable assets

Sell the building blocks

Catalog boilerplates, templates, stencils, word banks, schemas, evaluators, connectors, and validated workflow packs. Every item needs a version, licence, inputs, outputs, compatibility notes, checksum, price, and reproducible acceptance test.

Compute exchange

Rent spare GPU capacity safely

Offer opt-in, quota-bounded inference or batch jobs only after measuring real capacity. Execute tenant work in isolated sandboxes with timeouts, resource limits, signed job specs, no host secrets, and explicit data-retention rules. Never expose an unrestricted desktop or GPU to arbitrary code.

Physical distribution

DOOH and billboards

Represent each placement as a permissioned inventory item with location, time window, audience estimates, creative constraints, price, proof-of-play, and campaign outcome. Keep booking and creative publication approval-gated; do not buy inventory or publish creative automatically.

Trust layer

Evidence is the differentiator

Separate discovery, qualified demand, authorization, external action, payment settlement, fulfillment, delivery evidence, and independent verification. A green build is operational health, not proof of revenue.

Huge task: Marketplace that builds itself in bounded pieces

One task registry, decomposed by 777 into small idempotent work items. Each item must produce a durable artifact, run its verifier, and state what remains blocked. Reuse the existing CUBE, AgentBridge, Elohim, Gauntlet, commerce, and Truth Oracle substrate. Do not create a competing queue or truth ledger.

  1. First-dollar rail: trace the existing quote-comparison offer end to end; verify checkout attribution, settled payment, entitlement, fulfillment, and delivery evidence. Fix the earliest broken boundary.
  2. AgentBridge toll contract: standardize manifest, price estimate, scoped key, idempotency key, usage cap, error schema, and receipt against the existing gateway. Run read-only probes before any paid external action.
  3. Digital asset catalogue: add versioned metadata and acceptance tests for templates, stencils, word banks, connectors, and boilerplates. Deduplicate by canonical content hash and licence.
  4. Free B2B acquisition: generate genuinely useful, source-bound pages and free worksheets. Publish in small quality-gated cohorts; do not mass-generate thin doorway pages or claim SEO traffic before analytics confirms it.
  5. Cheap A2A checkout: measure unit cost, set a positive margin floor, expose machine-readable terms, and return signed receipts. Fail closed when price, permission, attribution, or fulfillment is missing.
  6. GPU capacity pilot: benchmark local inference and batch processing; advertise only measured spare capacity. Sandbox jobs, enforce quotas, keep secrets out of tenant contexts, and stop workloads when the owner is using the machine.
  7. Marketplace spine: canonical listing, entitlement, version pinning, licence, refunds/disputes, delivery evidence, reputation, and repeat purchase. Integrate with existing payment and fulfillment components.
  8. DOOH inventory adapter: define a vendor-neutral inventory schema and proof-of-play receipt; simulate campaigns first, then require explicit approval before spend or publication.
  9. Compounding gate: every cycle either advances verified external revenue or commits one non-duplicate, tested, useful artifact. Failed sources are UNKNOWN, not zero demand. No cloning a winner without independent evidence.
  10. Reliability and CI: verify scheduled execution, source freshness, artifact hash, site build, deploy health, and rollback path. Keep public effects approval-gated and preserve MTG/HappyHomarid/CollectorsCoast versus Amplissa/adult silo separation.

Acceptance contract

Download the machine-readable marketplace listing contract (JSON Schema). It defines versioned asset metadata, licensing, content hashes, interface contracts, pricing, acceptance tests, entitlements, provenance, and truth status.

  • Artifact is versioned, source-bound, and deduplicated.
  • Verifier is repeatable and records pass/fail plus evidence.
  • Every external action has an authority check and idempotency key.
  • Costs, limits, and the kill switch are explicit before a task is exposed to outside users.
  • Revenue remains NZ$0 until an independent buyer, settled payment, correct attribution, fulfillment, and delivery evidence are verified.
