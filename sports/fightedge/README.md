# FIGHTEDGE - Cross-Sport Intelligence

Evidence-first market intelligence across MMA, boxing, football, rugby, basketball, tennis, cricket, horse racing, greyhound racing, harness racing, motorsport, esports and other lawful sports markets.

Loop: CARD -> MARKET -> EVIDENCE -> PUNDITRY -> CONTRADICTIONS -> THESIS -> HUMAN REVIEW -> OUTCOME -> AUDIT.

No automatic wagering. No fabricated odds, sources, outcomes, buyers, revenue, or performance. Facts, attributed opinions, and hypotheses remain separate. Public release and live financial action remain approval-gated. Truth Oracle verifies evidence; Gauntlet challenges claims; CUBE provides the shared contract/kernel.
