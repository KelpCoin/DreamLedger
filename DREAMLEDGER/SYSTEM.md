# DreamLedger System

The system is a bounded economic operating loop.

## Core loop

OBSERVE -> MEMORY -> RETRIEVE -> REASON -> GAUNTLET -> AUTHORITY -> EXPOSURE -> TRANSACTION -> SETTLEMENT -> FULFILLMENT -> TRUTH -> LEARN -> REPLICATE

## Bidirectional search

Forward discovery starts with CUBE observations and constructs propositions.

Reverse discovery starts at a transaction boundary. The inverse Gauntlet defines what must be true for a candidate to survive. The inverse CUBE searches for observed opportunities capable of satisfying those conditions.

CUBE <-> INVERSE GAUNTLET is the joined search loop.

## Components

CUBE discovers and partitions opportunity observations.
Pinball refines bounded hypotheses.
Elohim constructs propositions.
Gauntlet removes unsupported candidates.
Factory-Factory compiles surviving candidates into bounded experiments.
AgentBridge coordinates execution jobs.
Worker A executes bounded internal work.
Worker B independently verifies the Worker A result.
DreamLedger stores economic memory and evidence.
Truth Oracle determines whether an economic claim is actually proven.
Marketplace and channel adapters expose approved offers.
Stripe is a settlement rail, not proof by itself.
Human authority controls irreversible external transitions.

## Truth

Revenue is only economically verified when an external buyer exists, payment has settled, attribution is correct, fulfillment occurred, and independent proof exists.

Internal rows, generated pages, checkout views, model outputs, tests, simulations, and un-attributed Stripe payments remain non-revenue evidence.

## Scaling

Scale follows replication. A mechanism is promoted only after independent external verification and successful fulfillment. Replication creates cells; cells can form silos; proven silos can be reproduced by the Factory-Factory compiler.

## Authority

Read, analyze, refine, test, compile, draft and execution-packet creation are system work.

External publication, outreach, spending, charging, deletion and production commerce changes require explicit human authority.

The system may prepare everything required for those actions but does not silently cross that boundary.
